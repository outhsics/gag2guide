Gear Shop

Gear provides gardening enhancements — sprinklers, watering cans and more. The shop restocks on a cycle (common items like the Common Sprinkler show a ~50% restock presence, rarer gear much less), so check back between weather events.

Known gear

GearRarityWhat it does
Common SprinklerCommonGardening enhancement — per in-game tips, sprinklers also boost seed pack luck
Common Watering CanCommonWaters crops; 10x from the WATERYOPLANTS code

Why gear matters: watering and sprinklers feed the growth curve that drives crop size — and size is a direct multiplier on sell price.
